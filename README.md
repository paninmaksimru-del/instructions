# Welcome — Цифровой профиль

Стартовый экран с анимированной волной и инструкцией по доступу.

Сайт: https://paninmaksimru-del.github.io/instructions/

Публикация через GitHub Pages из корня ветки `main`. Изменения в этой ветке автоматически обновляют сайт.

Откройте `index.html` в браузере. Для просмотра через локальный сервер из этой папки:

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

Адрес: http://127.0.0.1:8765/

Переходы:

- «Открыть портал» → https://profile.mos.ru
- «Доступ и инструкции» → `instructions.html#access`, актуальная инструкция.

Ранее опубликованные ссылки на разделы (например, `/#access` и `/#steps`) перенаправляются в соответствующий раздел `instructions.html`.

Состав:

- `index.html` — стартовый экран.
- `assets/welcome.css` — адаптивные стили и появление текста.
- `assets/wave.js` — анимированная точечная поверхность Canvas.
- `assets/welcome.js` — запуск анимации.
- `assets/fonts/` — локальный Onest и лицензия SIL OFL.
- `instructions.html` — страница инструкции.
- `assets/instructions/` — иллюстрации к инструкции и примеры заполненных карточек.

Страница содержит две инструкции: сначала «Цифровой профиль», затем «Дело в Москве».
У каждой инструкции свои материалы, поля, шаги заполнения и проверка результата.
Доступ в ИС РПП, редактирование и требования вынесены в общие разделы.
Инструкции и их подразделы доступны из бокового оглавления; на узком экране оглавление раскрывается над первым разделом.
Скриншоты раскрываются по запросу и открываются в увеличенном виде. Отметки чек-листов сохраняются в браузере отдельно для каждой инструкции.

Прямые ссылки: `instructions.html#cp-route` и `instructions.html#dm-route`.
Ранее опубликованные якоря `#systems`, `#access`, `#prep`, `#fields`, `#steps`, `#edit`, `#rules` сохранены.

Шрифт и цветовые токены взяты из публичного betaprofile.ru: Onest, фон #f3f3fd, текст #1d1c49, фиолетовый #4c40c3, базовый цвет частиц #9d95e6, усиленный для welcome до #8f84df. Движение волны создано заново.

При системной настройке уменьшения движения волна остаётся статичной, появление текста отключается. Анимация останавливается в скрытой вкладке. Для welcome-экрана не нужны CDN, сборка или подключение к сети.
